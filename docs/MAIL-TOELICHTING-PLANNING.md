# Mail-toelichting: zo maak je de barplanning

Korte tekst die je kunt doorsturen naar testers / barcommissie.

---

**Voorbeeldmail**

Onderwerp: Hoe maak je de barplanning in de app?

Hoi,

Kort hoe je de planning laat maken én verplichte mensen automatisch laat inschrijven.

Log in als barcommissie of admin en ga naar **Beheer → Planning**. Daar staan **4 stappen**:

1. **Diensten aanmaken / bijwerken**  
   De app zet de bar- en keukendiensten klaar voor ±6 weken, op basis van de dienstregels, thuiswedstrijden en activiteiten. (Importeer eerst wedstrijden via **Wedstrijden** als die nog niet binnen zijn.)

2. **Concept publiceren**  
   Kies eventueel een inschrijfdeadline en publiceer. Vrijwilligers kunnen zich dan zelf inschrijven (optioneel: mail vrijwilligers).

3. **Vul open plekken (verplicht)**  
   Dit is de knop die **verplichte mensen automatisch inschrijft** op open persoonlijke plekken (verplicht 1×/6 weken, VR18+, of inhaaldienst). De app verdeelt eerlijk.  
   Let op: **teamdiensten** vult de teamcoördinator via **Mijn team**, niet via deze knop.

4. **Maak officieel**  
   Vergrendelt het rooster. Daarna wijzigt alleen de barcommissie nog.

Op het **Dashboard** staat ook een snelle link “Barplanning maken” die je naar deze stappen brengt.

Vragen? Laat het weten.

Groet,  
Dennis

**Nog korter (WhatsApp / chat)**

Beheer → Planning:  
1) Diensten aanmaken → 2) Publiceren → 3) “Vul open plekken (verplicht)” = automatisch inschrijven → 4) Officieel.  
Teamdiensten apart via Mijn team (teamco).
